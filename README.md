An interactive sports analytics dashboard that uses Machine Learning to predict which national teams are mathematically most likely to reach the Quarter-Finals of the 2026 FIFA World Cup.

## 🧠 Project Overview
Does historical prestige win football tournaments, or does recent tactical form matter more? 

This project trains a **Random Forest Classifier** on 20 years of historical FIFA World Cup data (2002–2022). By extracting feature importances, the model mathematically proves that recent offensive form (goals scored and wins over the last 4 years) is a much stronger predictor of tournament success than a nation's historical World Cup pedigree. 

The backend predictions are served through a live, interactive **Streamlit** dashboard.

## ✨ Features
* **Machine Learning Predictions:** Generates statistical probabilities for all 48 teams qualifying for the 2026 World Cup.
* **Explainable AI (XAI):** Visualizes the specific feature weights (Goals Scored, Wins, Defensive Record, Historical Titles) that drive the model's decisions.
* **Interactive UI:** Users can search for specific national teams to view their AI-calculated odds and underlying driving metrics.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Processing & ML:** Pandas, Scikit-Learn
* **Frontend Dashboard:** Streamlit
* **Data Visualization:** Plotly Express
* **Deployment:** Streamlit Community Cloud

## 🚀 Local Installation & Setup

Want to run this project on your local machine? Follow these easy steps:

**1. Clone the repository**
```bash
git clone [https://github.com/TahmedulAbrarNiloy/world-cup-ai-predictor.git](https://github.com/TahmedulAbrarNiloy/world-cup-ai-predictor.git)
cd world-cup-ai-predictor
2. Install dependencies
Make sure you have Python installed, then run:

Bash
pip install -r requirements.txt
3. Run the application

Bash
streamlit run app.py
The dashboard will automatically open in your default web browser at http://localhost:8501.

📂 File Structure
app.py: The main Streamlit application script.

requirements.txt: List of Python dependencies required to run the app.

2026_WC_Predictions.csv: The exported predictions generated by the Random Forest model.

WC_Feature_Importance.csv: The exported weights showing which stats matter most.

📊 Data Source
The data used to train this model was sourced from the FIFA World Cup Team Dataset on Kaggle.
